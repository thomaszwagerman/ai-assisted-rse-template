# Governance

This is a small project with a single maintainer model by default. Edit this file as the
project grows.

- **Maintainers** (merge rights, releases): Your Name (@your-github-handle).
- **Contributors**: anyone who opens an issue or pull request.
- **Decisions** are made in public, in issues and pull requests, by lazy consensus.
  The maintainer has the final say.
- **Becoming a maintainer**: sustained, high-quality contributions and agreement from
  existing maintainers.
- **Continuity**: if maintainers become unavailable, the hosting institute may nominate
  new ones. Record the contact point here.
